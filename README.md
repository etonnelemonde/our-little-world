# Our Little World

GitHub Pages에 `index.html`을 업로드하면 사용할 수 있는 개인 여행 지도입니다.

## 이번 버전
- 상단 `핀 모아보기` 버튼 제거
- 오른쪽 하단 `n개의 장소` 버튼을 누르면 전체 장소 목록 열림
- 장소 목록에서 장소를 클릭하거나 `수정`을 누르면 해당 장소의 사진 + 현재 로그인한 사람의 코멘트만 수정 가능
- 장소 목록의 `삭제` 버튼으로 장소 전체 삭제 가능 (서경/문혁 로그인 사용자)
- 장소/좌표/핀 종류는 수정 화면에서 변경하지 않음
- 사진은 핀당 1장만 유지되며 새 사진 업로드 시 기존 사진 교체
- 코멘트는 기존 규칙대로 60~80자
